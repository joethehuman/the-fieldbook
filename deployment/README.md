# Deployment recipes

Recipes describe tested hosting configuration; service implementations live under `server/providers/`.

- [Vercel + hosted Supabase + Google sign-in](vercel/README.md): current supported installation.
- Standard Node configuration is available for local operation. Other managed-host recipes have not been verified.

Read [hosting and service contribution guidance](../docs/providers.md) before adding a recipe. Keep one installation/schema lineage and link maintained service setup instructions. Do not commit real accounts, domains, credentials or deployment exports.
