# Assigned learning

The current model is documented in [Learning model](learning-model.md) and [Learning groups and curricula](learning-groups.md). The historical migration filename `202609200003_required_learning.sql` remains unchanged. Apply it before the learning-groups migration.

Courses designated through groups count toward each learner’s completion percentage. There is no separate optional recommendation mode or enforcement mechanism. Updates personalize For you without affecting completion; all published content stays available.
